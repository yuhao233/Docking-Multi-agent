# 模型与第三方计算组件说明（Model Card）

本作品用于**虚拟筛选**：把受体结构与候选分子库转成可复核的候选清单。
打分来自经典物理打分函数；大语言模型仅用于自然语言交互与文字撰写，**不参与任何打分**。

## 1. 对接打分（关键预测指标的来源）

| 组件 | 版本 | 在本作品中的角色 | 输入 → 输出 | 适用范围 | 已知局限 |
| --- | --- | --- | --- | --- | --- |
| AutoDock Vina（`vina` 包） | 1.2.7 | **默认**打分与采样 | 受体 PDBQT + 配体 PDBQT + 盒 → 亲和力（kcal/mol）与位姿 | 同一受体、同一参数下的相对排序 | 经验打分函数；柔性受体未建模；分数非实验活性 |
| AutoDock4 + AutoGrid4 | 4.2.6 / 4.2.7 | 可选（`--engine autodock`） | 受体/配体 PDBQT + 格点图 → 自由能估计 | 需要经典 AD4 口径时 | 与 Vina 分数不可通约 |
| AutoDock-GPU | v1.6 | 可选（登记后 `--engine external`） | 同 AD4，格点图由 AutoGrid4 生成 | 大库加速 | 需 GPU；不支持格点参数库缺失的原子类型（会如实报错） |

**共同前提**：配体由 RDKit/Meeko 生成 3D 构象与 PDBQT（标准原子类型、Gasteiger 电荷）；
7 元及以上环按刚性环准备；受体与配体使用同一目标 pH 的质子化态（默认 7.4）。

## 2. 大语言模型（仅编排与文字）

| 项 | 说明 |
| --- | --- |
| 作用 | 把自然语言指令转成结构化任务；在预定义工具集合内调度；撰写报告文字与结论表述 |
| 不参与 | 打分、排序、参数数值决定（这些由计算内核与配置决定，并全程留痕） |
| 调用方式 | OpenAI 兼容 HTTP 接口；端点在 `.env` 配置（`LLM_BASE_URL`/`LLM_API_KEY`/`LLM_MODEL`） |
| 实测示例 | DeepSeek `deepseek-flash`（推理温度为 0，禁思考模式） |
| 输入 | 用户指令、上传文件路径、工具返回的结构化结果（大库只回摘要 + 头部行） |
| 输出 | 工具调用参数、结论文本（经 pydantic 结构化校验） |
| 已知局限 | 可能误解指令或复述数据；因此关键结论必须能由产物中的数值复核；不配置 LLM 时 `screen.py` 仍可完整运行 |

## 3. 辅助计算组件（可选，缺失时自动回退并如实说明）

| 组件 | 版本 | 用途 | 缺失时的行为 |
| --- | --- | --- | --- |
| P2Rank | 2.5.1 | 口袋检测（`--auto-site`） | 回退内置几何法（fpocket 思路） |
| pdb2pqr + PROPKA | 3.x | 受体按目标 pH 重新分配质子化态 | 跳过并按结构原有质子化态计算，报告注明 |
| Dimorphite-DL | 2.0.2 | 配体 pKa 微观态枚举 | 回退内置 pKa 规则表（近似），逐分子记录所用引擎 |
